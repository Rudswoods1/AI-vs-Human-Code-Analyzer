AI vs Human Code Analyzer О проекте

Литературный обзор: AI-Generated vs Human-Written Code

Этот прототип вдохновлён работами, сравнивающими код, созданный моделями ИИ, и код, написанный людьми, по метрикам корректности, стиля, безопасности и сложности.

Используемые метрики в этом прототипе
  1. Pytest: smoke‑тест импорта
  2. Pylint: Стиль кода (0/10)
  3. Bandit: Безопасность
  4. Radon MI: Сложность/поддерживаемость
